# Asset derivati (trimmed)

Questi PNG sono **copie generate automaticamente** da `scripts/trim-assets.mjs`.

- **Sorgente originale (non modificata):** `../` (cartella `img/` padre)
- **Comando rigenerazione:** `npm run trim-assets`
- **Cosa fa:** rimuove i margini completamente trasparenti (visible bounding box)
- **Manifest:** `manifest.json` + `src/game/spriteManifest.json`

Non editare manualmente i file qui dentro: verranno sovrascritti al prossimo trim.
